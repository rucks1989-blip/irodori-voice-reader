# Irodori Voice Reader — Windows版

AIチャットの文章をIrodori-TTSのキャラクター音声で読み上げるWindows x64向けソフトです。
Chrome拡張1.2.26とMozilla署名済みFirefox拡張1.2.27を同梱しています。
GitHub Releaseの **IrodoriVoiceReader-Windows-test.zip** をダウンロードしてください。「Source code」は導入用ZIPではありません。

## 一般ユーザー向けの導入手順

1. 配布一式を展開し、フォルダー内の `setup.bat` を実行します。BATだけ移動しないでください。
   ダウンロードに失敗しても、その場で何度でも再試行できます。手動取得したファイル・ZIP・展開済みフォルダーは好きな保存先から参照できます。[取得・復旧の詳しい案内](docs/downloads-and-recovery.md)
2. Chromeのみ／Firefoxのみ／両方を選びます。
3. 保存先を選びます。最初から選択画面が開き、前回の場所を既定値として表示します。「参照」で別のフォルダーを選べます。最低5GBの空き容量を確認し、その場所に `chrome-` などの専用フォルダーを作成します。モデル・Python環境・エンジン・ダウンロード・一時ファイルもこの保存先に置きます。
   GPU声質安定版まで追加する場合は、展開キャッシュや通常版の保持分も含めて15GB程度の空きを推奨します。任意ビルドにはさらに開発ツール用の容量が必要です。
4. 検出された既存環境と、新しい導入先・専用ポートを確認します。既存環境は上書きしません。Firefoxの接続ヘルパーが別の導入先に登録済みの場合は、上書きせず停止します。既存Firefox環境の移行は自動では行いません。
5. 専用Python環境、ハッシュ検証済みモデル、完成済みエンジンを準備します。既存モデルを選んだ場合も新しい導入先へコピーします。
6. 完成品が不足する場合は「対応完成品を用意して再開／このPC向けにビルド／中止」を選びます。ビルドは任意です。自動で開始したり、CPUへ切り替えたりしません。
7. 利用権限のある参照WAVを登録し、通常・声質安定プロファイルの音声生成を確認します。WAV生成成功と声質安定アルゴリズムの有効性確認は別です。声質安定版を導入しなかった場合は、セットアップ完了時にその旨を画面・コンソール・`docs/finish.html` に表示します。
8. 導入先の `docs/finish.html` に従い、最後に拡張を手動追加します。

途中の「安全に中止」で今回起動した処理を終了します。同じブラウザー選択で再実行すると専用環境を再開できます。再開時は前回の保存先をそのまま使い、空き容量だけ再確認します。
既存環境のプロセス名による一括終了は行いません。新しい別環境は `setup.bat -NewEnvironment` で作成します。選択した保存先は `%LOCALAPPDATA%\IrodoriVoiceReader\Installer\location.json` に記録し、次回の既定値にします。小さなセッション情報と確認画面だけをこのフォルダーに残し、導入本体・状態・ログ・ダウンロード・一時ファイルは選択した保存先へ置きます。

### Chromeへの最後の追加

`chrome://extensions/` → デベロッパーモード → パッケージ化されていない拡張機能を読み込む → 案内された導入先の `chrome-extension` を選択します。
Chromeの拡張一覧に表示される名前は「Irodori Voice Reader」です。サイドバーで接続・Voiceを確認し、ChatGPTと自動再生をONにして回答検出・再生を確認してください。既存版の設定は初期化しません。

### Firefoxへの最後の追加

1. Firefoxのアドレス欄に `about:addons` と入力します。
2. 歯車ボタン →「ファイルからアドオンをインストール」を選びます。
3. 完了案内に表示されたインストール先の `IrodoriVoiceReader-Firefox-1.2.27-signed.xpi` を選び、「追加」を許可します。

XPIは展開・編集しません。署名設定の無効化や開発者版Firefoxは不要です。同じFirefoxプロファイルの同じ拡張IDへの更新では既存設定を保持します。既に利用中の拡張を削除・初期化する必要はありません。

### 声質安定版を後から追加する

通常版のみで導入しても問題ありません。インストール先の **「声質安定版追加する.bat」をダブルクリックすると後から追加できます**。
先に拡張の操作で音声エンジンを停止してください。配布ZIP側ではなく、セットアップ完了画面に表示されたインストール先のBATを使います。
既存の `setup.bat -Repair` と同じ修復処理を使用し、Voice・モデル・ユーザー設定は保持します。
CPU方式は同梱の声質安定版完成品を使用します。GPU方式は既存のGPU自動検出を使い、対応する声質安定版完成品を優先します。対応完成品がなければ、既存の選択画面から完成品の指定・任意ビルド・中止を選べます。任意ビルドには対応CUDA ToolkitとC++ビルド環境が必要です。上流の通常版完成品は声質安定版の代わりにはなりません。確認なくビルドしたり、CPU方式へ変更したりしません。
追加後は拡張のエンジン選択で「通常版」と「声質安定版」を切り替えられます。元の通常版実行ファイルも保持します。
GPU声質安定版の同梱完成品は **CUDA sm86** 向けです。特定の製品名に固定せず、検出されたGPU世代との一致で選びます。他のGPU世代は同梱完成品での動作確認済みとはしていません。既存の任意ビルドでは、そのPCで検出した世代向けに作成します。

## 完成品と任意ビルドの違い

GPU推論とソースのコンパイルは別工程です。対応GPU完成品を使えばCUDA Toolkit・Visual Studio Build Tools・CMakeは不要です。NVIDIAドライバーと必要な実行時ライブラリは必要です。

| 項目 | 完成品を利用 | 任意でビルド |
|---|---|---|
| 通常の選択 | こちらを優先 | 完成品不足や開発変更の反映時に選択 |
| GPU音声生成 | 対応GPUで実行 | 完成後にGPUで実行。コンパイル自体はCPUも使用 |
| 導入時間 | 取得・展開・設定が中心 | 数十分以上かかる場合あり |
| 容量 | モデル約1.09GB、実行ファイル・依存DLL・Python環境 | 左記に加えてツール・ソース・中間生成物。数GB〜数十GB |
| ツール | 原則ビルドツール不要 | 対応CUDA Toolkit、C++ Build Tools、Git、CMake等 |
| 音声と機能 | 完成品に含まれる処理を利用 | ビルドだけで高品質になるわけではない。ソースとパッチの内容が影響 |
| 互換性 | GPU世代・ドライバー・DLL版の検証が必要 | 指定GPUをコンパイラーがサポートする必要あり |

同一モデル・設定でも実装や演算環境で数値差が生じる場合があります。ファイル名・文字列・短文WAVの一致だけで声質安定機能の有無を断定しません。実際の要求、設定、処理ログを照合します。
再構築は開発者向け `scripts/build-backend.ps1` に残しています。通常ユーザーに必須のツール導入ではありません。

## 既存機能と設定

ChatGPT回答検出、自動・手動読み上げ、キャラクター／ナレーション振り分け、話者タグ・別名・Voice ID、会話括弧、Voice準備確認のmain修正を維持しています。新しい導入先の接続情報は生成ファイルへ保存し、利用者向けの設定項目は増やしていません。

### 話者タグの区切り記号
Chrome・Firefoxの詳細設定／サイドバーで「話者タグの開始記号」「話者タグの終了記号」を変更できます。既定は `【` と `】` です。`[` と `]`、`＜` と `＞`、`{` と `}`、複数文字も指定できます。空欄・改行を含む設定は既定の組へ戻ります。
内側の登録名・別名・Voice IDを従来どおり解決します。「会話として扱う括弧」とは独立した設定です。例えばタグを `[]`、会話括弧を `「」` と `（）` にすると、`[クリス]（一）（二）地の文` はナレーションON・タグ優先ONで「一」「二」をクリスVoice、地の文をナレーションVoiceへ送ります。既存のVoice・モデル・キャラクター設定の初期化は不要です。
設定同期は同じブラウザプロファイル内の詳細設定とサイドバー間です。ChromeとFirefox間の設定移動は設定のエクスポート／インポートを使用します。

## 通常版のみの導入（更新）

工程4では通常版を先に準備します。通常版の完成品が配布一式になければ、既存のGPU対応 `audiocpp_server.exe` を指定でき、DLLとともに新しい環境へコピーします。元の環境は変更しません。対応GPUの判断は最終的に実際の音声生成で確認し、GPUごとに必ず別の実行ファイルを要求するわけではありません。
声質安定版は「今回は導入しない／完成品を使用／任意ビルド」から選択します。未導入は正常な選択です。通常版だけで導入完了できます。GPU推論にCUDAソースビルドは必須ではありません。

コマンド実行では `setup.bat -Browsers chrome -StableMode skip -Backend cuda -BackendDirectory "完成品のフォルダー"` を使用できます。`-ModelPath "モデルファイル" -ReferenceWav "参照WAV"` も指定できます。対話を省略する検証用指定は `-Unattended -NoOpenGuide` です。
声質安定版完成品は `-StableMode prebuilt -StableBackendDirectory "完成品のフォルダー"`、明示的な再構築は `-StableMode build` です。通常版の任意ビルドは安定化パッチを適用しません。声質安定版の追加失敗時は通常版を保持して継続します。
未導入モードへの要求は「声質安定版はインストールされていないため、現在使用できません。」と返し、通常版へ自動変換しません。拡張UI・既存の声質安定版設定は削除しません。
