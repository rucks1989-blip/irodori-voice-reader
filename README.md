# Irodori Voice Reader — 配布版の統合作業

非公開リポジトリの作業ブランチです。完成配布版ではありません。main・公開設定・Releaseは変更しません。
Chrome/Firefoxの機能基準は main `3bde458`、セットアップの基準はローカル作業版です。
拡張ソースは両方1.2.25です。インストール済みFirefoxや署名済み1.2.25 XPIとは別の成果物です。

## 一般ユーザー向けの導入手順

1. 配布一式を展開し、フォルダー内の `setup.bat` を実行します。BATだけ移動しないでください。
2. Chromeのみ／Firefoxのみ／両方を選びます。
3. 検出された既存環境と、新しい導入先・専用ポートを確認します。既存環境は上書きせず、各ブラウザーの拡張ID・Native Hostも分離します。
4. 専用Python環境、ハッシュ検証済みモデル、完成済みエンジンを準備します。既存モデルを選んだ場合も新しい導入先へコピーします。
5. 完成品が不足する場合は「対応完成品を用意して再開／このPC向けにビルド／中止」を選びます。ビルドは任意です。自動で開始したり、CPUへ切り替えたりしません。
6. 利用権限のある参照WAVを登録し、通常・声質安定プロファイルの音声生成を確認します。WAV生成成功と声質安定アルゴリズムの有効性確認は別です。
7. 導入先の `docs/finish.html` に従い、最後に拡張を手動追加します。

途中の「安全に中止」で今回起動した処理を終了します。同じブラウザー選択で再実行すると専用環境を再開できます。
既存環境のプロセス名による一括終了は行いません。新しい別環境は `setup.bat -NewEnvironment` で作成します。

### Chromeへの最後の追加

`chrome://extensions/` → デベロッパーモード → パッケージ化されていない拡張機能を読み込む → 案内された導入先の `chrome-extension` を選択します。
名前は「Irodori Voice Reader (独立環境)」です。サイドバーで接続・Voiceを確認し、ChatGPTと自動再生をONにして回答検出・再生を確認してください。既存版の設定は初期化しません。

### Firefoxの現時点の制限

独立環境のソースと `firefox-isolated-unsigned.xpi` を生成します。既存FirefoxのHostがあっても、新しい専用Hostへ登録できます。
ただし生成した拡張は未署名であり、通常版Firefoxへの恒久導入は未完成です。既存の署名済みXPIを変更・流用すると署名や固定接続先との整合が失われるため、代用しません。
安全に分離した開発用Firefoxへの一時読み込みと、正式な署名・接続先配布方式の確立が残っています。現在使用中のFirefoxでは検証しません。

## 完成品と任意ビルドの違い

GPU推論とソースのコンパイルは別工程です。対応GPU完成品を使えばCUDA Toolkit・Visual Studio Build Tools・CMakeは不要です。NVIDIAドライバーと必要な実行時ライブラリは必要です。

| 項目 | 完成品を利用 | 任意でビルド |
|---|---|---|
| 通常の選択 | こちらを優先 | 完成品不足や開発変更の反映時に選択 |
| GPU音声生成 | 対応GPUで実行 | 完成後にGPUで実行。コンパイル自体はCPUも使用 |
| 導入時間 | 取得・展開・設定が中心 | 数十分以上かかる場合あり |
| 容量 | モデル約1.09GB、実行ファイル・依存DLL・Python環境 | 左記に加えてツール・ソース・中間生成物。数GB〜数十GB |
| ツール | 原則ビルドツール不要 | 対応CUDA Toolkit、C++ Build Tools、Git、CMake等 |
| 音声と機能 | 完成品に含まれる処理を利用 | ビルドだけで高品質になるわけではない。ソースとパッチの内容が影響 |
| 互換性 | GPU世代・ドライバー・DLL版の検証が必要 | 指定GPUをコンパイラーがサポートする必要あり |

同一モデル・設定でも実装や演算環境で数値差が生じる場合があります。ファイル名・文字列・短文WAVの一致だけで声質安定機能の有無を断定しません。実際の要求、設定、処理ログを照合します。
再構築は開発者向け `scripts/build-backend.ps1` に残しています。通常ユーザーに必須のツール導入ではありません。

## 実行した手順と検証範囲

今回実行したセットアップ入口の診断コマンドは `setup.bat -CheckOnly` です。
完全導入用の `setup.bat -Browsers chrome|firefox|both` は、各値を一つ選んで実行します。診断成功を完全導入成功とは扱いません。

[実機・コード検証の結果と未解決事項](docs/integration-validation.md) を参照してください。
対応GPU完成品の配布構成とFirefox署名が未解決のため、この作業ブランチを一般ユーザー向け完成版として配布しないでください。既存ZIPも最新版ソースとは別です。

## 既存機能と設定

ChatGPT回答検出、自動・手動読み上げ、キャラクター／ナレーション振り分け、話者タグ・別名・Voice ID、会話括弧、Voice準備確認のmain修正を維持しています。新しい導入先の接続情報は生成ファイルへ保存し、利用者向けの設定項目は増やしていません。

### 話者タグの区切り記号
Chrome・Firefoxの詳細設定／サイドバーで「話者タグの開始記号」「話者タグの終了記号」を変更できます。既定は `【` と `】` です。`[` と `]`、`＜` と `＞`、`{` と `}`、複数文字も指定できます。空欄・改行を含む設定は既定の組へ戻ります。
内側の登録名・別名・Voice IDを従来どおり解決します。「会話として扱う括弧」とは独立した設定です。例えばタグを `[]`、会話括弧を `「」` と `（）` にすると、`[クリス]（一）（二）地の文` はナレーションON・タグ優先ONで「一」「二」をクリスVoice、地の文をナレーションVoiceへ送ります。既存のVoice・モデル・キャラクター設定の初期化は不要です。
設定同期は同じブラウザプロファイル内の詳細設定とサイドバー間です。ChromeとFirefox間の設定移動は設定のエクスポート／インポートを使用します。

## 通常版のみの導入（更新）

工程4では通常版を先に準備します。通常版の完成品が配布一式になければ、既存のGPU対応 `audiocpp_server.exe` を指定でき、DLLとともに新しい環境へコピーします。元の環境は変更しません。対応GPUの判断は最終的に実際の音声生成で確認し、GPUごとに必ず別の実行ファイルを要求するわけではありません。
声質安定版は「今回は導入しない／完成品を使用／任意ビルド」から選択します。未導入は正常な選択です。通常版だけで導入完了できます。GPU推論にCUDAソースビルドは必須ではありません。

コマンド実行では `setup.bat -Browsers chrome -StableMode skip -Backend cuda -BackendDirectory "完成品のフォルダー"` を使用できます。`-ModelPath "モデルファイル" -ReferenceWav "参照WAV"` も指定できます。対話を省略する検証用指定は `-Unattended -NoOpenGuide` です。
声質安定版完成品は `-StableMode prebuilt -StableBackendDirectory "完成品のフォルダー"`、明示的な再構築は `-StableMode build` です。通常版の任意ビルドは安定化パッチを適用しません。声質安定版の追加失敗時は通常版を保持して継続します。
未導入モードへの要求は「声質安定版はインストールされていないため、現在使用できません。」と返し、通常版へ自動変換しません。拡張UI・既存の声質安定版設定は削除しません。
