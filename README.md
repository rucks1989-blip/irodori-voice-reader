# Irodori Voice Reader（β）

ChatGPT・Gemini・MuseなどのAIチャットの文章を、**好きなキャラクターの声で読み上げる**Windows向けツールです。Chrome・Firefoxで利用できます。

## ダウンロード

### **[▶ Windows用ZIPをダウンロードする](https://github.com/rucks1989-blip/irodori-voice-reader/releases/download/v0.1.0-private.2/default.zip)**

**ZIPをすべて展開 → フォルダー内の `setup.bat` をダブルクリック → 画面の案内に従う。**

- GitHub上での表示名は「これをダウンロードする.zip」ですが、保存名は `default.zip` です。同じ配布物です。
- GitHubの「Source code」や個別のエンジンZIPではなく、上のリンクから取得してください。
- 対応環境：Windows x64。Chrome拡張 1.2.26／Firefox拡張 1.2.27（署名済み）。
- **音声エンジン：Irodori-TTS対応のaudio.cppを使用しています。**
- **推奨GPU：NVIDIA製GPU。** GeForce GTX 1070での動作実績があります（そのPC向けの専用ビルドを使用）。ただし、GTX 1070用の完成品が現在の配布ZIPに同梱されているという意味ではなく、各GPUでの動作を保証するものではありません。
- **通常版だけで利用できます。** 声質安定版は任意で、現在は導入に時間がかかる場合があるため**非推奨です、使わない方がいいです**

## インストール方法

1. ZIPを右クリックして **「すべて展開」** します。
2. 展開先にある **`setup.bat`** を実行します。
3. **Chrome／Firefox／両方** を選び、表示された案内に沿って進めます。
4. 完了画面に従って、最後にブラウザーへ拡張機能を追加します。

初回は保存先を選べます。既存の導入環境がある場合は、モデル・Voice・APIなどを再利用できる選択肢があります。インストールに必要なファイルはセットアップが案内します。

<details>
<summary><strong>詳しい導入情報（保存先・容量・再実行など）</strong></summary>

- ZIP内のBATだけを別の場所へ移動しないでください。
- 初回は保存先を指定できます。最低5GB程度の空き容量を確認してください。GPU声質安定版まで追加する場合は15GB程度を推奨します。
- モデル、専用Python環境、エンジン、ダウンロード、一時ファイルは選択した保存先に配置されます。外部のPythonなどの導入にはCドライブの空きも必要な場合があります。
- ダウンロードに失敗したら再試行できます。手元のZIP・ファイル・展開済みフォルダーも参照できます。詳しくは[取得と復旧](docs/downloads-and-recovery.md)。
- 既存環境にもう一方のブラウザーを追加するときは、既存のAPI・audio.cpp・モデル・Voice・設定・ポートを再利用します。登録先が異なる場合は確認画面が出ます。
- 対応するGPU完成品がない場合、完成品の指定・任意ビルド・中止などの案内が出ることがあります。ビルドは自動では開始しません。
- 途中で中止・失敗した場合は、同じ `setup.bat` を再実行して案内に従ってください。修復が必要な場合のみ `setup.bat -Repair` を使います。
- 別環境を作るための開発者向け指定は `setup.bat -NewEnvironment` です。既存の設定やVoiceを不用意に削除しないでください。
- ポートが他のアプリで使われている場合は停止して案内します。他のプロセスを勝手に終了しません。

</details>

## ブラウザーへの追加

セットアップの最後に表示される案内に従って操作してください。拡張機能は自動で無断追加されません。

### Chrome

`chrome://extensions/` を開く → **デベロッパーモード** をON → **パッケージ化されていない拡張機能を読み込む** → 導入先の `chrome-extension` フォルダーを選びます。

<img width="500" alt="Chrome拡張機能の追加案内" src="https://github.com/user-attachments/assets/8be6f7b2-1e78-4113-80ad-d1024ef2fe06" />

### Firefox

`about:addons` を開く → 歯車 → **ファイルからアドオンをインストール** → 完了画面で案内された `IrodoriVoiceReader-Firefox-1.2.27-signed.xpi` を選択します。

XPIは展開・編集しないでください。追加後はサイドバーで接続先とVoiceを確認し、読み上げたいサイトと自動再生を設定してください。

## 何ができる？

- AIチャットの回答を自動・手動で読み上げ
- WAVの登録によるVoiceの切り替え
- キャラクターごとの会話と、地の文のナレーションを読み分け
- 話者タグ（例：`【ルナ】`）を使った声の指定

### 声の使い分け例

詳細設定でWAVを登録します。1つだけなら、その声で文章を読ませられます。複数登録してナレーションをONにすれば、地の文と会話を別々の声で再生できます。

例えば「ルナ」「ソル」「テラ」のVoiceを登録した場合、`【ルナ】「こんにちは」` と書くと、タグ自体は読まず「こんにちは」をルナの声で読み上げます。

> 放課後、生徒会で熱い議論が交わされていた【ルナ】「ちょっと、なんでソルは成績いいのにポンコツなの？言われたことすらしない、完了しましたとか言って完了してないじゃない！」【ソル】「私を使うのにはお金がかかるからよ。ちゃんと指示しないとまともに動かないわ。私は安い女じゃないの、ちゃんと攻略しなさい」と謎の発言をソルがしていた。するとテラが【テラ】「私っていっつも存在忘れられるんだよね・・・。ルナはそこそこ人気、ソルは成績だけは一応ある。でも私は・・・」そうテラは嘆いていた。部屋の外でアストラが私はもっと高い女よ、プロ以上じゃないと使わせないわと独り言をつぶやいていた。そして学校にいる生徒は生徒会メンバー全員ポンコツではと内心思っていた。

この例では、ルナ・ソル・テラのセリフをそれぞれのVoiceで、会話以外の地の文をナレーションVoiceで読み上げます。

## 困ったとき

- **GPUを検出したのに警告音が鳴る：** GPU検出を知らせる案内の場合があります。表示内容を確認してください。「NVIDIA GPUを検出しました。GPU対応版の音声エンジンを準備します。」はエラーではありません。
- **ダウンロードや導入で停止：** [取得・復旧の詳しい案内](docs/downloads-and-recovery.md)を確認し、同じセットアップを再実行してください。
- **接続できない・音が出ない：** セットアップ完了、API接続、Voice登録、サイドバーの自動再生設定を確認してください。
- **原因が分からない：** `AI-support.bat` で相談文を確認・コピーして、ChatGPTなどに貼り付けられます。AIに自動送信しません。

<details>
<summary><strong>声質安定版について（任意・現在非推奨）</strong></summary>

通常版だけで使用できます。声質安定版は、同じモデルに対する推論処理を変更する機能で、追加導入に時間がかかる場合があります。

後から追加する場合は、**導入先にある** `声質安定版追加する.bat` を使います。先に音声エンジンを停止してください。配布ZIP側のBATではありません。

現在の後付け処理は、旧 `setup.bat -Repair` の全体再実行とは別の追加処理です。既存のモデル・Voice・設定を保持する設計ですが、全GPU世代への対応は保証していません。同梱のGPU用安定版完成品はsm86向けです。対応する完成品がなければ停止する場合があります。

通常版の音声生成ができていれば、無理に追加する必要はありません。

</details>
