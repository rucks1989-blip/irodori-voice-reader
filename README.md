# Irodori Voice Reader — 別PC導入試験版

ChatGPT・Muse・Geminiの回答や選択した文章を、PC内のIrodori-TTSで読み上げるChrome／Firefox拡張です。

**現在はPrivateの導入試験版です。別PCでの完全な導入は未検証です。**
拡張機能は1.2.23、セットアップは0.1.0-private.1です。API Only版とは別製品です。

## はじめての方：ここから

### 1. 配布一式を取得

GitHubへ、このリポジトリを閲覧できるアカウントでログインしてください。

**[最新の試験用Releaseを開く](https://github.com/rucks1989-blip/irodori-voice-reader/releases/tag/v0.1.0-private.1)**

Releaseの **`IrodoriVoiceReader-Windows-test.zip`** をダウンロードし、右クリック → **「すべて展開」** してください。
「Source code」ではなく「Windows-test」の方を選ぶと、CPU完成品と署名済みFirefox拡張が揃っています。

> GitHubを配布元にしていますが、ブラウザーで複数ファイルを取得する負担を避けるため、試験用一式は圧縮してあります。Gitのインストールやコマンド入力は不要です。
> 非公開ファイルを取得するための個人トークン入力は不要です。

### 2. `setup.bat` をダブルクリック

展開したフォルダーの **`setup.bat`** を開き、表示される内容を確認してください。
拡張子が表示されない場合は「setup」というWindowsバッチファイルです。

- 最初は展開したフォルダー内から実行してください。BATだけを移動しないでください。
- 初期配置先は `%LOCALAPPDATA%\IrodoriVoiceReader\App` です。Chrome拡張はここから読み込みます。
- モデル約1.09GBと必要なPythonパッケージを、説明後に取得します。
- **CPU方式**：同梱された声質安定対応エンジンを使います。遅いですがCUDA・ビルドツールは不要です。Microsoft Visual C++実行環境が不足していれば、確認後に追加します。
- **NVIDIA GPU方式**：対応完成品がなければ、同意後にソースから自動ビルドします。Git、Visual Studio C++ Build Tools、対応CUDA Toolkitが必要になり、導入時にそれぞれ確認します。
- GPUビルドは数十分以上、追加ダウンロードと作業領域に数十GBが必要な場合があります。空き容量は選択前に確認してください。
- モデルを既に持っていれば、ファイル選択で検証して再利用できます。元ファイルは変更しません。
- 任意で、ご自身または利用権限のある短いWAVを選択してVoiceを登録できます。個人の声は配布していません。
- 終了後もウィンドウに「停止」と出ていれば未完了です。原因を直して同じ `setup.bat` を再実行できます。

**Windowsの警告が出た場合**：製品名、取得元、ReleaseのSHA256SUMSを確認してください。ウイルス対策・SmartScreenの無効化は必要ありません。組織管理PCの制限は管理者へ相談してください。

### 3. 最後に拡張機能を追加

セットアップが開いた日本語の案内に沿って、**本人がChrome／Firefoxへ追加**します。

- Chrome：`chrome://extensions/` → デベロッパーモード → パッケージ化されていない拡張機能を読み込む → 案内されたフォルダーを選択。
- Firefox：`about:addons` → 歯車 → ファイルからアドオンをインストール → 案内された署名済みXPIを選択。
- サイドバーでAPI接続とVoiceを確認し、使うサイトと自動再生をON。対象サイトを再読み込みして新しい質問を送ります。
- Voice未登録なら、Voice管理で利用権限のある参照WAVを追加してください。「環境準備完了」と「音声生成テスト済み」は区別して表示されます。

[画像付きの追加手順](docs/browser-install.md)

## 対応と注意

- Windows x64向け。ARM64は対象外。Windows PowerShell 5.1を使用します。
- Pythonは3.12 x64。見つからなければ許可後にwingetで導入します。依存パッケージはアプリ専用venvに入れます。
- CPU完成品は固定ソース＋安定化パッチのビルドです。各PCの速度・メモリ消費は異なります。
- このCPU完成品はSSE4.2/BMI2対応CPU向けです。古いCPUで起動できない場合はその環境を報告してください。少なくとも16GB RAMを推奨しますが、他アプリの使用量によっては不足します。
- NVIDIA GPUでは、実際のGPU世代を調べ、その世代をコンパイルできるCUDAを確認します。未対応なら止まります。ドライバーの自動更新はしません。
- AMD／Intel GPU高速化はこの試験版では対象外。CPU方式を使用できます。
- 8765と8091が他アプリで使用中なら停止します。既存プロセスを勝手に終了しません。
- 同じWindowsユーザーに別の通常版Native Hostが登録済みの場合は上書きしません。**今回の目的どおり別PC、または別Windowsユーザーで試してください。**
- セットアップは通常ユーザーで実行します。ビルドツール等の公式インストーラーが必要な場合だけWindowsの管理者確認が出る可能性があります。
- APIは`127.0.0.1:8765`、audio.cppは`127.0.0.1:8091`のみ。通常版と声質安定版は共有サーバーです。
- PC起動時の自動起動、ファイアウォール例外、拡張の無断追加は行いません。
- API Only版と同じサイトの読み上げを両方ONにすると二重読み上げになる場合があります。

## 困ったとき：先にこちら

| 状況 | 最初に試すこと |
|---|---|
| 取得が途中で失敗 | 接続と空き容量を確認し、setup.batを再実行。モデル取得は再開します |
| GitHubが404になる | 対象アカウントでログインしているか、リポジトリの閲覧権限があるか確認 |
| assetsのファイルがない | ReleaseのWindows-test一式を取得。「Source code」は開発用です |
| Python／wingetが見つからない | Microsoft Storeの「アプリ インストーラー」を更新。必要ならWindowsを再起動 |
| ビルドツール追加後に止まった | 再起動を求められた場合は再起動し、setup.batを再実行 |
| CUDA・GPUエラー | ドライバーを公式の案内で確認。まずCPU方式でも試せます |
| ポート使用中 | 他のIrodoriを本人の操作で終了。無関係なプロセスは終了しないでください |
| 声が選べない | 個人Voiceは同梱していません。ご自身の参照WAVを登録してください |
| 拡張から接続できない | セットアップ完了・ヘルパー登録・正しい拡張IDを確認。ブラウザーを再起動 |
| 再試行時の既存環境エラー | 保存先が今回の試験版か確認。別の製品や旧環境は自動上書きしません |

### それでも解決しない場合のみ、AIへ相談

**`AI-support.bat`** を開く → 内容を確認 → 「相談文をコピー」 → ChatGPTなどへ自分で貼り付けます。

- 失敗工程・実際のエラー・Windows/GPU情報が入ります。
- ユーザー名・PC名・ローカルパス・代表的な秘密値は伏せ字にします。送信前に必ず確認してください。
- 会話・音声・モデル・設定一式・生ログは添付しません。AIへ自動送信もしません。
- AIからリポジトリが見えない場合は、必要なソースのみ本人が選んで共有します。
- 生ログはローカルの `%LOCALAPPDATA%\IrodoriVoiceReader\Installer` にあります。公開Issuesへそのまま貼らないでください。

## 次回から

追加した拡張のサイドバーを開くと、登録されたヘルパーがローカルAPIを起動します。毎回setup.batを実行する必要はありません。
同じ試験版の再実行は復旧用です。別バージョンへの自動上書き更新は、この試験版では行いません。

## ソースから試す方

GitHubの「Code → Download ZIP」またはcloneでも取得できます。その場合、同じReleaseの署名済みFirefox XPIとCPU backend ZIPを `assets/` に置きます（名前とハッシュはdistribution.json参照）。

開発チェック：

```powershell
powershell -NoProfile -File scripts/validate.ps1
python scripts/privacy_scan.py
python -m unittest discover -s tests
```

利用条件は [LICENSE](LICENSE)、外部コンポーネントは [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md) を参照してください。

ソースにはモデル、個人Voice、会話、生成音声、個人設定、ログ、署名用認証情報は含めません。

### 話者タグの区切り記号
Chrome・Firefoxの詳細設定／サイドバーで「話者タグの開始記号」「話者タグの終了記号」を変更できます。既定は `【` と `】` です。`[` と `]`、`＜` と `＞`、`{` と `}`、複数文字も指定できます。空欄・改行を含む設定は既定の組へ戻ります。
内側の登録名・別名・Voice IDを従来どおり解決します。「会話として扱う括弧」とは独立した設定です。例えばタグを `[]`、会話括弧を `「」` と `（）` にすると、`[クリス]（一）（二）地の文` はナレーションON・タグ優先ONで「一」「二」をクリスVoice、地の文をナレーションVoiceへ送ります。既存のVoice・モデル・キャラクター設定の初期化は不要です。
設定同期は同じブラウザプロファイル内の詳細設定とサイドバー間です。ChromeとFirefox間の設定移動は設定のエクスポート／インポートを使用します。
