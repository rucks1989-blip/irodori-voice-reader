# Windowsダウンロード・復旧検証（2026-11-04）

## 採用した方式

- Windows curl → Python `ssl.create_default_context()` / urllib。証明書・ホスト名検証を維持し、TLSバイパスやWindows設定変更はしない。
- 固定ファイルの容量・SHA-256、展開済みフォルダーは検証済みZIPから生成したファイル別SHA-256で照合する。
- 手動参照は配布ソースと別の場所を許可。必要ファイルだけをコピーし、元の選択ファイル／フォルダーは変更しない。
- URLが失われても版・ファイル名・検索語・ハッシュを保持。未確認ミラーや互換性不明な最新版は登録しない。

## 試作品の評価

提供物は展開済みの `README.txt`、`download-irodori.ps1`、`ダウンロード.bat` として確認した。原本は変更せず、配布一覧・コミット対象から除外する。

- PowerShellスクリプトはUTF-8 BOMなしで、Windows PowerShell 5.1で15件の構文エラーを再現した。採用する既存スクリプトは日本語を扱うためUTF-8 BOMを維持する。
- 繰り返し選べる復旧メニュー・手動参照の考え方は有用。ただし既存インストーラーに接続されていない独立入口であり、そのままは採用しない。
- `distribution.json` と同じ場所に置く説明は、利用者が取得物を自由な場所から参照する要件を満たさない。CPU完成品が未登録という説明も現在の定義と異なる。
- 既存インストーラー側に代替HTTPS・7操作の復旧ループ・検証済みフォルダー取り込みを統合した。試作品の採用自体を目的にはしない。

## 既存成果の保持

- Chrome ChatGPTの既存動作を維持し、回帰テストを実施する。
- Geminiは実Chromeで新規送信→回答取得→キュー→WAV生成を確認済みの暫定成功。長期運用、全ての履歴／画面遷移条件での誤再生防止は未確認であり、今回追加の長時間検証はしない。
- 声質安定版の新規ビルド471.2秒、一致する完成済み成果物の再利用1.83秒という既存測定を保持する。新規ビルド自体の高速化を示す数値ではない。今回、再測定目的の長時間ビルドは行わない。

## 検証の境界

実際の `setup.bat` は独立したソース・セッション・インストール先を使用する。テスト専用curlで終了35／`CRYPT_E_REVOCATION_OFFLINE (0x80092013)`を注入し、Pythonは実在するHTTPS配布元へ接続する。404用URLもテスト用ソースだけに設定し、本番のURLは変更しない。

既存正常環境のモデル・Voice・設定・Native Hostを初期化しない。Firefox拡張ソース・設定・署名は今回変更しない。Eドライブ実機参照、完全新規PCへのシステムツール導入、GPU版の今回の通し導入、Chrome・Firefox双方の完全新規導入は今回の完了判定に含めない。

## 確認済みの結果

- 実際のsetup.batで配布ソースの整合性検査を通過。通常curlでPython wheelを取得し、certifiだけcurl終了35を注入するとPythonの実HTTPSへ切り替わり、固定SHA-256検証後に9依存パッケージをオフライン導入できた。
- モデルのcurl終了35と、実配布元へのHTTPS 404で全方式を失敗させ、インストーラーが復旧画面で待ち続けることを確認。「今すぐ再ダウンロード」「別の取得方法」はそれぞれ失敗後に同じ画面へ戻った。
- 正確なモデル名・ファイル名・版・用途・ハッシュ・配布ページ・URL・検索語・実際の404／TLSエラーを表示した。AI相談文は正式リポジトリURLを維持し、PCユーザー名やローカルパスを除去した。別方式で404が確定した場合、相談文にはその最新エラーを記録する。
- 中断後に同じ保存先へ再開し、導入済みPython依存パッケージを再取得・再導入しないことを確認。誤ったモデルを入れたフォルダーは拒否され、インストーラーは復旧画面へ戻った。
- Dドライブの既存GGUFをネイティブファイル選択画面から指定し、容量・SHA-256検証後にモデル工程を通過した。モデルの大型再ダウンロードは行っていない。
- 実機で見つかった一時パスのMAX_PATH超過は、取り込み用一時名を短くすることで修正し、通常のWindowsパス長で再現する回帰テストを追加した。
- Cドライブに展開したCPU完成品をネイティブフォルダー選択画面から指定し、Dドライブへ取り込んだ。配置された10ファイル全ての容量・SHA-256が一致し、選択元の未登録 `untrusted-extra.exe` は配置されなかった。
- 通常版CPUエンジンを実際に起動し、専用API経由で参照音声付きの日本語TTS要求からRIFF/WAVEを取得した。声質安定版の追加や再ビルドは行っていない。
